# Principes actifs de conception

## Vision

Le joueur doit avoir l’impression de mener une enquête, pas de remplir une fiche de grammaire.

La langue française sert à observer, comparer, comprendre, reformuler, déduire et justifier.

## Principes à préserver

- Enquêtes courtes et jouables en classe.
- Interface 2D principalement statique.
- Documents courts, lisibles et crédibles.
- Progression claire sans annoncer toute la solution.
- Pédagogie discrète intégrée à l’action.
- Peu d’objets, chacun avec une fonction compréhensible.
- Personnages aux fonctions narratives différenciées.
- Déblocages justifiés par l’histoire, pas par une logique arbitraire.
- Indices progressifs qui invitent à relire plutôt qu’à deviner.
- Résolution prudente et réparatrice plutôt qu’accusatrice.
- Décor vivant facultatif qui enrichit le monde sans créer une seconde enquête parasite.

## Référence actuelle : La salle fantôme

`La salle fantôme` constitue le meilleur exemple actuel d’une chaîne de progression où les documents et la langue produisent réellement l’enquête :

1. une convocation contient une anomalie ;
2. le plan permet de constater l’absence de la salle ;
3. les personnages reformulent et contextualisent ;
4. une archive montre que l’ancien nom a existé ;
5. une note donne la correspondance ;
6. un personnage explique l’origine administrative de l’erreur ;
7. le joueur accomplit une action concrète de rectification.

Cette structure est une référence, pas une recette obligatoire.

## Variations admises

Une enquête peut être principalement :
- documentaire ;
- fondée sur des témoignages ;
- spatiale ;
- centrée sur un objet ;
- procédurale ;
- relationnelle ;
- construite autour d’une fausse piste ;
- légère et atmosphérique.

## À éviter

- Transformer l’enquête en quiz grammatical.
- Multiplier les QCM quand une observation ou une interaction suffit.
- Créer un lieu uniquement pour porter une étape.
- Donner la solution trop tôt dans un dialogue ou un briefing.
- Cacher un blocage derrière une navigation non réversible.
- Multiplier les documents sans fonction claire.
- Faire croire qu’un élément facultatif est indispensable.
- Confondre objet physique, document, indice, preuve et interprétation.
- Complexifier le moteur pour résoudre un problème local.
- Ajouter un backend, un score, du crafting ou un moteur de jeu lourd sans besoin démontré.

## Critère de qualité

Une bonne étape d’enquête doit répondre à au moins une de ces fonctions :

- observer quelque chose ;
- apprendre quelque chose ;
- comparer deux informations ;
- reformuler un problème ;
- faire naître ou invalider une hypothèse ;
- débloquer une action concrète ;
- enrichir l’atmosphère sans brouiller la piste principale.

Si une étape ne remplit aucune de ces fonctions, elle doit être supprimée ou repensée.
