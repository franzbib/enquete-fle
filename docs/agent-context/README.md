# Statut de ce dossier

Les fichiers numérotés de `docs/agent-context/` ont servi de mémoire de travail pendant les premières versions du projet. Ils sont conservés pour comprendre l’historique des décisions, mais plusieurs décrivent un état ancien : un ou deux scénarios, absence de sauvegarde, feuille de route antérieure à `La salle fantôme`, etc.

Ils ne doivent donc plus être utilisés seuls comme source de vérité par un agent.

## Documents canoniques actuels

Lire d’abord :

1. `../../README.md` ;
2. `../STATUS.md` ;
3. `../DESIGN_PRINCIPLES.md` ;
4. `../architecture.md` ;
5. `../DECISIONS.md`.

En cas de contradiction :

1. l’état réel du code et des validations prévaut ;
2. les documents canoniques ci-dessus décrivent l’intention actuelle ;
3. les fichiers historiques expliquent comment le projet est arrivé à cet état.

Ne pas supprimer les fichiers historiques : ils restent utiles pour retracer les choix, mais leurs mentions de version et de prochaines actions peuvent être périmées.
